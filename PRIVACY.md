# Privacy Notice

Effective date: 27 July 2026

## Local processing

Marketing Analytics is designed to process marketing exports locally on the
user's Windows device. The desktop application starts internal services only on
`127.0.0.1` for its own interface.

The application does not intentionally transmit uploaded files, generated
charts, report contents, company names, or analytics results to a Marketing
Analytics-operated remote service.

## Local files

The application creates local working files, charts, and PDF reports in the
current user's Windows profile and Documents folder. The user controls backup,
retention, deletion, and access to those files.

## Third-party services

Downloading a release from GitHub is subject to GitHub's own terms and privacy
practices. The application may also be affected by Windows, security software,
or network policies controlled by the user or their organization.

## User responsibility

Before importing data, ensure that its collection, export, storage, and use are
lawful for the relevant people, platforms, clients, and jurisdictions.

## Changes

This notice may be updated in a future release. The effective version is stored
in this repository and distributed with the application.

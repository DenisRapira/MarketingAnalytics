# Changelog

Все заметные изменения проекта фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.1] - 2026-07-27

### Added

- Открытая лицензия Apache License 2.0, NOTICE и уведомления о сторонних компонентах.
- Инструкция проверки SHA-256, политика конфиденциальности и security policy.
- Контрольная сумма `SHA256SUMS.txt` в Windows-релизе.

### Changed

- Удалена необязательная GPL-зависимость `python-Levenshtein` из официальной сборки.

## [1.0.0] - 2026-07-27

### Added

- Первый публичный Windows x64 релиз Marketing Analytics.
- Локальный desktop-клиент с WebView2, автоматическим backend и PDF-отчётами.
- Импорт XLS, XLSX и CSV, автоматическое распознавание метрик, бенчмарки и сравнение периодов.
